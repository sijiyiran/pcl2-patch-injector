# PCL2 补丁注入工具

恢复 PCL2 官方 2.99.x 被禁用的「下载」与「整合包安装」入口——就地注入 IL 补丁，自动备份原文件。
同时内置**启动器原地更新**：选中你正在用的 PCL2，自动检测版本，发现新版本后一键原地升级（配置全保留）。

## 功能特点

- **单文件免安装**：内嵌 dnlib 与参考版实现，空目录双击即用
- **就地注入补丁**：选中你的 `Plain Craft Launcher 2.exe`，点「注入补丁」即可，自动备份为 `.bak`
- **自动检测**：程序版本 / 是否 PCL2 / 是否已注入 / 能否注入
- **安全写入**：临时文件 + 原子替换，失败不损坏原文件；已注入文件不会重复修改
- **检测版本 → 原地更新启动器（v1.6+）**：
  - 选中启动器后自动对比 GitHub 官方最新**正式版**
  - 有新版本时点「更新启动器」：**原地覆盖同一个 exe**，自动 `.bak` 备份，PCL 的配置/主题/账户全保留
  - 更新到官方正式版 2.99.0.0（可完整恢复下载功能）；不会升级到 2.99.0.1（官方已删除下载 UI 入口）
  - 已是最新 / 本地较新 / 可更新 三种状态自动提示
- **v1.5 深色主题**：深色卡片界面（GLM 优化），保留全部功能

## 使用方法

1. 双击 `PCL2补丁注入工具.exe`（免安装，需 .NET Framework 4.8）
2. 选择或直接拖入 `Plain Craft Launcher 2.exe`，工具会自动检查（版本 / 类型 / 补丁状态 / 可注入性）
3. 若需要更新启动器：看「③ 启动器更新」卡片
   - 显示「发现新版本」时点「更新启动器」→ 确认 → 原地升级（自动备份，PCL 配置保留）
   - 已是最新时按钮显示「已是最新」（禁用）
4. 若需要打补丁：检查通过后点击「注入补丁」→ 确认框点「开始注入」
5. 几秒内完成，按钮变绿「补丁已生效」；启动 PCL2 进入下载页即可

> 更新/下载走 GitHub 官方仓库：jsDelivr CDN 主通道 + GitHub API 兜底；
> 失败时可用「在浏览器打开 GitHub」手动下载。

## 适用范围

PCL2 2.99.x。**推荐使用 2.99.0.0**（可完整恢复下载页与整合包安装）；
2.99.0.1 官方已删除「原版游戏」下载 UI 入口，注入后无法恢复下载页，不建议更新到该版本（工具也不会自动升级到它）。

## 补丁原理

PCL2 2.99.0.0 以"为遵守相关法律法规"为由，把 3 处入口换成了提示/异常占位（下载/安装核心代码其实都还在）：

1. `PCL.PageDownloadInstall::LoaderInit` —— 假加载器恢复为真实的版本清单加载器 `DlClientListLoader`
2. `PCL.ModModpack::ModpackInstall(String,String,String)` —— 整合包类型分发恢复：CurseForge / HMCL / MMC / MCBBS / Modrinth / 启动器包 / 普通压缩包
3. `PCL.ModModpack::ModpackInstall()` —— 恢复"选择文件 → 后台安装"入口

工具以 2.13.1.1（下载功能正常）为参照在 IL 层恢复上述实现；全量方法级差分确认只改了这 3 个方法。
字符串匹配已适配 2.99.0.1 的提示语变化（"不再提供" vs "暂时不再提供"）。

## 更新通道说明

- 官方更新服务器已关闭，官方改为在仓库发布 `最新正式版.zip`（内含 `Plain Craft Launcher 2.exe`）
- v1.6.1 起更新目标固定为最新 **Release tag**（当前 2.99.0.0）：
  `https://cdn.jsdelivr.net/gh/Meloong-Git/PCL@<tag>/最新正式版.zip`，失败时切 GitHub API（`contents?...&ref=<tag>`）兜底
- 下载后校验：zip 可打开、内含 PCL2 exe、版本信息正确，才落盘；全程临时文件 + 原子替换

## 安全说明

- 注入/更新前自动备份为 `<原文件名>.bak`；若备份已存在，会生成 `<原文件名>.yyyyMMddHHmmss.bak`
- 写入采用"临时文件 + 原子替换"，失败不会损坏原文件
- 已注入过的文件会被识别为「已注入 / 无需注入」，不会重复修改
- 选错文件（非 PCL2、非 exe、文件被占用、网络失败）都会给出明确中文提示
